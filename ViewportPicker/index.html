Viewport Animation Picker

An animation picker system built from Maya locator shapes, with a Qt GUI to manage how the viewport picker is placed in the camera view.

[C++, Python]

Role: Sole developer.

Key features

  • Pickers can be created easily from existing controllers — users can cast controllers to camera space and create pickers
  • A UI for adding and removing individual pickers manually
  • Independent visibility control for picker shapes in the viewport
  • Supports all Maya viewport manipulations, including display/selection mask, display layer, and isolate selection
  • Customizable color, selection color, and transparency for each picker item
  • Pickers can be grouped into containers; each container allows an image background with an alpha channel
  • Lightweight I/O as a disk file
  • Pickers are saved with the Maya rig scene — no additional data files need to be maintained
  • GUI picker panel supports selection undo, with Qt item selection synced to the Maya scene selection
