PoseManager

A facial rig-authoring tool for both prerendered and real-time in-game characters, producing joint-based, blendshape-based, or hybrid face rigs. Each control, joint, and blendshape coefficient can take multiple inputs, and each input channel can in turn drive multiple output targets — a multiple-input, multiple-output (MIMO) driver-driven mapping resolved through a proprietary plug-in node.

This tool has delivered every facial rig on Overwatch, the Diablo IV in-game cinematics, the World of Warcraft in-game cinematics, and Blizzard's prerendered shorts.

[Python, C++, PyQt, Maya]

What it shows

  • Tool UI for managing and triggering facial poses
  • A Tracer (Overwatch) view for pose-space deformation
  • Facial test pass exercising the rig across a range of Overwatch characters
  • Prerendered pose/expression playback
